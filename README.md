# PscoresPlus

An R package for computing extended P-scores across clinically important value (CIV) combinations in network meta-analysis.

## Features

- Computes extended P-scores across various CIV(s) and combinations.
- Supports multiple outcomes.
- Can export results to Excel.
- Multiple graphs to visualize findings

### From CRAN
```r

```

### From GitHub
```r
install.packages("remotes")

```

## Usage

```r
library(PscoresPlus)
```

## Main function

- `pscore_civs()`: computes extended P-scores across CIV combinations.
